## 🚀 Featured Project

### OneHelp — AI-Powered Customer Support Platform

**OneHelp** is a customer-support platform designed to help Sri Lankan ISP customers submit and manage complaints using **voice and text**.

The project combines:

- Next.js
- Spring Boot
- Python
- AI / NLP
- Whisper Speech-to-Text
- LangChain
- PostgreSQL
- MongoDB
- Vector Database

The goal is to make customer support smarter by connecting users with the right service provider.
